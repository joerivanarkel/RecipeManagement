- **Story map:** `C:\Repos\RecipeManagement\docs\product\story-map.md` — source of truth for numbered stories (001-024). Spec files are generated per story via `/spec <number>`.
- **Issues:** GitHub repo `joerivanarkel/RecipeManagement`, created via the `github` MCP server's `issue_write` tool with `method: "create"`. CLAUDE.md authorizes filing issues without asking first.
- **Architecture docs:** `docs/architecture/` follows the arc42 template.
